== 3. TTL confirmado directo en Redis ==
$ docker exec sged_redis redis-cli KEYS "api_externa:*"
api_externa:standings:PL

$ docker exec sged_redis redis-cli TTL "api_externa:standings:PL"
86380
(86400 s = 24h configuradas en football.api.ttl-cache-seconds; 86380 s es el
 TTL a los pocos segundos de escribirse la clave, confirma la ventana de 24h)
